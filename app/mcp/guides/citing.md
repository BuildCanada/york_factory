# How to cite Build Canada data

- One record: paste its `cite`. It names the publisher, the dataset, the source file's digest, the release and
  the record's gid.
- A computed number (a summary row): cite the operation and the release, and name the source datasets. For
  example: *Build Canada Data API, release 11, GET /v1/entities/01J9ZK4T6M8Q2R5V7X3B1N0C4D/spending/summary?fiscal_year=2024-25&as_of=11;
  source: Treasury Board of Canada Secretariat, Proactive Disclosure of Grants and Contributions.*
- Say what the number is: "agreements worth" for grants, "contract value" for contracts, "commitments" for
  Global Affairs projects.
- Every tool result lists what to cite in `citations`, and its text ends with them.

More: https://data.buildcanada.com/api/concepts/provenance.md
